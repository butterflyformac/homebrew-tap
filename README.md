# Butterfly for Mac: Homebrew tap

[Butterfly](https://butterflyformac.com/) is a scrolling tiling window manager for macOS.
Every window sits side by side on one strip that scrolls past the edge of your screen,
and you move along it with the trackpad, mouse or keyboard.

```sh
brew install --cask butterflyformac/tap/butterfly
```

Butterfly updates itself after install, so `brew upgrade` is not needed.
Free for 7 days, then a one-time payment. macOS 14 Sonoma or later, Apple silicon and Intel.

- Website: https://butterflyformac.com/
- Releases: https://github.com/butterflyformac/releases
